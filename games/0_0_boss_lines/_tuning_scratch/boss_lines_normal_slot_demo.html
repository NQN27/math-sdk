Notes / known simplifications

This engine reimplements the real mechanic from game_config.py/game_bonus.py/game_executables.py: real reel CSVs, real 15-line matching (contiguous run from reel 0, wild substitution, min kind=3), real per-instance symbol damage ranges, real wild 2x-highest-substituted damage rule, real boss HP/Dam table with ±25% variance and the 35%-spread reroll, real column→boss routing with live fallback re-evaluation, real mid-spin multi-stage-clear (a hot pass can chain through several boss trios in one spin), real +50/+50 Player HP grant on every stage clear, real Elixir (10-100% of current HP, rounded to nearest 10) and Booster (x2 damage next spin) triggers, real sequential-strip tumble refill with stage-removed-symbol resampling, and the real unconditional per-spin counter-attack.

Known simplification: boss-defeat cash pops use a small illustrative placeholder table, not the real 21-tier reward_drop_weights_normal_bonus table (that table's exact weights weren't transcribed here) — so the total-win number shown is NOT the tuned economy. The tuned mean/ median/ratio numbers already confirmed for these two configs live in CONFIRMED_CANDIDATES.md; this demo is for mechanic/feel, not economy verification.
